# VS Code split terminal side choice

## Intent

Pressing Ctrl+Alt+S on Linux X11 or Windows should first show a VS Code choice for **Left** or **Right**. The selected side determines where a fresh terminal window opens beside VS Code.

## Behavior

- The terminal occupies one third of the usable monitor width on the selected side. VS Code occupies the other two thirds.
- Choosing **Right** retains the current layout. Choosing **Left** mirrors it.
- Dismissing the choice has no side effects: no terminal launches and neither window moves.
- Existing local-workspace restrictions, workspace-root selection, focus, window-placement safeguards, and keyboard shortcut remain in effect.

## Approach

Use VS Code's native Quick Pick in each platform's embedded extension code. Pass the chosen side into the existing Linux layout calculation or Windows placement helper. This keeps the prompt visually consistent across platforms and avoids a new GUI dependency. An input box would require parsing free text; separate commands or shortcuts would not meet the requested first prompt.

## Constraints

The extension is generated by the Linux shell and Windows PowerShell installers, so both embedded sources need the same user-facing choice. Keep the current terminal launch and monitor-detection architecture. No release or installation is part of this change.
